Cost-savings rationale

  • One Sonnet call per run. Stage 5 is the only high-cost step; everything else is programmatic or Nova Lite.
  • HITL interrupt before stage 5. On hitl gate band, middleware halts BEFORE the Sonnet call → CO previews + can edit constraints. Resume runs the draft only if CO approves.
  • Withhold path skips drafting. On withhold gate, the agent's response-format + system prompt direct it to terminate without calling draft_section_text. Saving depends on the model honoring tool-order steering — eval gate catches drift.
  • Lightweight extractor model. Nova Lite at $0.06/M in · $0.24/M out vs. Sonnet $3/M · $15/M — ~50× input / ~60× output cost gap. Spec pins the exact model via config.BEDROCK_EXTRACT_MODEL knob.
  • No LLM judge in the loop. Phase 1 keeps the Nova Micro judge at the request edge (still stubbed; Phase 1.5).
  • Opportunistic retrieval. Stage 2 skipped when naics/set_aside null — zero wasted Mongo + rerank cost.

Why these stages, in this order

Order is not hardcoded in the handler — the agent loop chooses tool order, constrained by: (a) tool docstrings describing preconditions ("must call retrieve_far_clauses before draft_section_text"), (b) the response_format validator requiring citations non-empty when outcome="draft_returned", and (c) the HITL middleware interrupt point on stage 4. Stage 5 is the highest-cost step and runs only when stage 4 returned pass (or the CO has explicitly resumed past a non-pass decision). Stage 6 hard-fails the run if stage 5's claim_chunk_map references any chunk_id not in stage 1's retrieved set — the same guarantee M2 ships today, now enforced inside the agent loop.

Where the existing UI maps in

Wizard steps 4 (Section C), 6 (Section H), 10 (Section L), 11 (Section M) are the only AI-drafted steps — each is one POST /draft-solicitation/section call → one agent run end-to-end. Section I (clauses) is retrieved-only and is served by the existing POST /retrieve endpoint, not by this agentic endpoint — the M2 _FAR_SECTION_ENUM excludes I and is preserved verbatim (ADR-0012 D3, D5.1). Other sections (A, B, D, E, F, G, J, K) bypass the agent entirely — pure human textarea, provenance tagged human client-side.
